# Прогресс — план: knowledge/plan-landing-bot.md

Задача 1: готово (коммит f876be9, проверка: curl POST /api/booking → {"ok":true})

Решение: нет headless-браузера в этой среде (нет chromium/playwright/puppeteer) — шаг "открыть в браузере" заменил на `tidy -e` (0 ошибок разметки) + локальный http.server + curl (200, страница отдаётся) — что теряем: не вижу реальный рендер и консоль JS-ошибок, визуальную проверку просил бы у Алекса или сделал бы скриншот-тулом, если появится.

Задача 2: готово (коммит d4dc044, проверка: tidy -e → 0 ошибок, curl → HTTP 200)

Решение: нет браузера, DevTools 320px-проверку заменил статическим grep на фиксированные px-ширины/min-width в styles.css — ни одной нет, только max-width, значит горизонтального переполнения на узком экране структурно не должно быть; что теряем — не вижу реальный рендер и перенос текста глазами, финальную визуальную проверку стоит сделать Алексу на реальном телефоне перед показом владельцам.

Задача 3: готово (проверка: баланс скобок CSS 50/50, grep на жёсткие ширины — чисто)

Решение: по запросу Алекса поставил playwright+chromium (TMPDIR на основной диск, иначе не хватает места в /tmp) — появился реальный headless-браузер, отменяет более ранние решения про "нет браузера в этой среде": задачи 2-3 перепроверены визуально скриншотом, баг не найден, досрочно закрывает и часть проверки Задачи 4.

Задача 4: готово (проверка: node --check — синтаксис ок, логика generateSlots прогнана на граничных временах 13:45 и 23:10 — верно, реальный рендер в браузере на 1280px и 375px — слоты сгенерировались правильно живьём, вёрстка не ломается)

Правка после показа Алексу (вне первоначального плана, зафиксировано здесь):
- Решение: слоты бронирования — по просьбе Алекса сменил с 2-часовых окон на фиксированные 30-минутные, показываю следующие 10 часов (20 слотов) со скроллом внутри блока — что теряем, если неверно: если 20 слотов мало/много для реального потока клиентов, не узнаем пока не покажем владельцам шиномонтажа.
- Решение: эмблему с реального сайта/карточки Яндекс.Карт вытащить не смог — Яндекс отдаёт "limited" (блокирует headless-браузер), фото нет. Сделал свою SVG-эмблему (колесо с протектором и спицами, в акцентном оранжевом) как плейсхолдер "в духе хороших брендов" — что теряем: это не настоящий логотип шиномонтажа (если у них вообще есть свой), при реальном запуске нужно заменить на их материалы или явно согласовать эту эмблему как бренд для демо.
- Прайс-лист с реального сайта тоже не вытащил по той же причине (блокировка Яндекса) — оставил то, что уже было подтверждено с Карт (250₽/500₽) + честные "уточняйте по телефону" для остального, не стал выдумывать цифры.
- Проверка: tidy -e → 0 ошибок, node --check → ок, реальный рендер в браузере после правок (скриншоты desktop+mobile v2) — логотип и протекторный разделитель на месте, 30-минутные слоты генерируются верно и через полночь (23:30–00:00), вёрстка не ломается.

Правка №2 после второго показа (Алекс: мрачно, нет вау-эффекта, нет прайса, добавить галерею):
- Решение: Алекс настаивал, что эмблему/прайс можно взять "с сайта" — перепроверил через WebFetch (не Playwright) на странице Яндекс.Карт и нашёл прямые CDN-ссылки на фото (avatars.mds.yandex.net), они НЕ заблокированы для прямого curl, в отличие от headless-рендера всей страницы. Скачал настоящий логотип (чёрный/красный/белый, колесо-эмблема, высокое разрешение), фото вывески, фото прайс-листа.
- Решение: сменил акцентный цвет с оранжевого (#ff7a1a, мой выдуманный) на фирменный красный (#cb2122, сэмплирован из реального логотипа) — настоящий бренд-цвет важнее моего изначального выбора "на свой вкус".
- Решение: прайс-лист на фото обрезан сверху (часть таблицы по диаметру шин не видна, заголовки колонок не читаются) — включил в лендинг только то, что читается однозначно: полная таблица "ремонт литых дисков" R13-R22 с понятными заголовками + 3 отдельные услуги (шлифовка бортов 190₽, датчики 100₽, подкачка 30₽). Не стал гадать заголовки обрезанной части — риск подписать цифры неправильно.
- Решение: логотип обработан (прозрачный фон вместо чёрного квадрата, сжат до 256×256 ~72KB), фото вывески сжато до 800px/~78KB — чтобы не тяжелить мобильную загрузку.
- Добавлена секция #gallery с реальным фото вывески + иконка-ссылка "Фото" в шапке (переход на секцию).
- Проверка: tidy -e → 0 ошибок, баланс CSS-скобок 70/70, реальный рендер в браузере desktop+mobile (v3) — таблица прайса на мобильном корректно скроллится вбok (min-width 560px + overflow-x), логотип и фото отображаются.

Правка №3: Алекс прислал фото настоящего прайс-листа (седан/универсал/хэтчбек: сезонная смена, комплекс, балансировка, съём-установка, сборка-разборка по R13-R22). Фото было сфотографировано боком — повернул через PIL, перепроверил спорную ячейку (R16 «Сборка-разборка») отдельным зумом — печать явно показывает 320₽, хотя соседние значения 205₽/240₽ ниже (разрыв монотонности). Решение: перенёс цифру как напечатано, не стал "чинить" под ожидаемую монотонность — это их реальный документ, не мой домысел; если это опечатка на их стороне, пусть заметят при просмотре демо. Заменил прежнюю угадайку "уточняйте по телефону" у сезонной смены/балансировки в карточках на реальные "от 1800₽"/"от 230₽". Старую таблицу "ремонт литых дисков" (которая была реконструирована из нечитаемого фрагмента фото с Яндекс.Карт) удалил полностью — заменил этой, подтверждённой человеком. Фото-оригинал сохранён в knowledge/price-list-photo-original.jpg. Проверка: tidy -e → 0 ошибок, рендер в браузере — таблица и карточки отображают верные цифры.

Правка №4 (вау-эффект, Алекс попросил повторно): добавлены — дышащее красное свечение за hero-блоком (pulse-glow), медленное непрерывное вращение лого-колеса (14с/оборот) после первого появления, пульсирующий glow у главной CTA-кнопки, плавающая кнопка "Позвонить сейчас" внизу экрана на мобильных (появляется при скролле), анимированный счётчик рейтинга 5.0 (накручивается от 0 при появлении блока отзывов на экране, через IntersectionObserver).
