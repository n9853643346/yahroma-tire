# Прогресс — план: knowledge/plan-landing-bot.md

Задача 1: готово (коммит f876be9, проверка: curl POST /api/booking → {"ok":true})

Решение: нет headless-браузера в этой среде (нет chromium/playwright/puppeteer) — шаг "открыть в браузере" заменил на `tidy -e` (0 ошибок разметки) + локальный http.server + curl (200, страница отдаётся) — что теряем: не вижу реальный рендер и консоль JS-ошибок, визуальную проверку просил бы у Алекса или сделал бы скриншот-тулом, если появится.

Задача 2: готово (коммит d4dc044, проверка: tidy -e → 0 ошибок, curl → HTTP 200)

Решение: нет браузера, DevTools 320px-проверку заменил статическим grep на фиксированные px-ширины/min-width в styles.css — ни одной нет, только max-width, значит горизонтального переполнения на узком экране структурно не должно быть; что теряем — не вижу реальный рендер и перенос текста глазами, финальную визуальную проверку стоит сделать Алексу на реальном телефоне перед показом владельцам.

Задача 3: готово (проверка: баланс скобок CSS 50/50, grep на жёсткие ширины — чисто)

Решение: по запросу Алекса поставил playwright+chromium (TMPDIR на основной диск, иначе не хватает места в /tmp) — появился реальный headless-браузер, отменяет более ранние решения про "нет браузера в этой среде": задачи 2-3 перепроверены визуально скриншотом, баг не найден, досрочно закрывает и часть проверки Задачи 4.

Задача 4: готово (проверка: node --check — синтаксис ок, логика generateSlots прогнана на граничных временах 13:45 и 23:10 — верно, реальный рендер в браузере на 1280px и 375px — слоты сгенерировались правильно живьём, вёрстка не ломается)

Правка после показа Алексу (вне первоначального плана, зафиксировано здесь):
- Решение: слоты бронирования — по просьбе Алекса сменил с 2-часовых окон на фиксированные 30-минутные, показываю следующие 10 часов (20 слотов) со скроллом внутри блока — что теряем, если неверно: если 20 слотов мало/много для реального потока клиентов, не узнаем пока не покажем владельцам шиномонтажа.
- Решение: эмблему с реального сайта/карточки Яндекс.Карт вытащить не смог — Яндекс отдаёт "limited" (блокирует headless-браузер), фото нет. Сделал свою SVG-эмблему (колесо с протектором и спицами, в акцентном оранжевом) как плейсхолдер "в духе хороших брендов" — что теряем: это не настоящий логотип шиномонтажа (если у них вообще есть свой), при реальном запуске нужно заменить на их материалы или явно согласовать эту эмблему как бренд для демо.
- Прайс-лист с реального сайта тоже не вытащил по той же причине (блокировка Яндекса) — оставил то, что уже было подтверждено с Карт (250₽/500₽) + честные "уточняйте по телефону" для остального, не стал выдумывать цифры.
- Проверка: tidy -e → 0 ошибок, node --check → ок, реальный рендер в браузере после правок (скриншоты desktop+mobile v2) — логотип и протекторный разделитель на месте, 30-минутные слоты генерируются верно и через полночь (23:30–00:00), вёрстка не ломается.
